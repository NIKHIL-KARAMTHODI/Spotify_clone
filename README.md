# Spotify Clone 🎵

A responsive Spotify Clone built using **React (JSX)** and **CSS**, designed to replicate the look and feel of the Spotify web player. This project focuses on modern UI design, component-based architecture, and responsive layouts.

---

## 🚀 Features

- 🎧 Spotify-inspired user interface
- 📱 Fully responsive design
- 🎵 Music player layout.
- 📂 Playlist and Library sections
- 🔍 Search functionality UI
- 🎨 Modern CSS styling
- ⚛️ Reusable React components

---

## 🛠️ Built With

- React.js
- JSX
- CSS3
- JavaScript (ES6+)
- Vite
